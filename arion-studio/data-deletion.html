ARION Studio — 내 데이터를 지우는 방법

ARION Studio에 연결한 계정 정보와 저장된 데이터는 언제든 삭제할 수 있습니다. 아래 세 가지 방법 중 편한 것을 쓰시면 됩니다.

방법 1 — 앱에서 직접 (가장 빠름)

  1. ARION Studio를 엽니다.
  2. 계정 연결 화면에서 지우려는 계정 옆의 [해제]를 누릅니다.
  3. 해제하는 즉시 해당 계정의 액세스 토큰이 서버에서 삭제됩니다.

방법 2 — Meta 계정 설정에서

  1. Instagram 또는 Facebook 앱에서 설정 → 보안 → 앱 및 웹사이트로 이동합니다.
  2. 목록에서 ARION Studio를 찾아 삭제를 선택합니다.
  3. Meta가 저희 서버로 삭제 요청을 전달하며, 해당 이용자의 토큰과 연결 정보가 삭제됩니다.

방법 3 — 이메일 요청

  • 제목: [ARION Studio] 데이터 삭제 요청
  • 연결한 계정의 사용자명(예: @arion_0722)
  • 전부 삭제인지, 특정 항목만 삭제인지

  • 이미 게시된 글 — Threads·Instagram·Facebook에 올라간 게시물은 각 플랫폼에 남습니다. 해당 앱에서 직접 삭제하셔야 합니다. ARION Studio에서 연결을 해제해도 이미 올라간 글이 사라지지는 않습니다.
  • 법령상 보존 의무가 있는 기록 — 해당 법정 기간 동안 보관 후 파기합니다.
